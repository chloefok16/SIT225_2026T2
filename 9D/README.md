# SIT225 9D - Data Capture and Activity Analysis

This folder contains the implementation and outputs for Task 6D.

Activities:
- 0 = no activity
- 1 = tilt
- 2 = side-to-side wave

Files include:
- smartphone accelerometer capture and Plotly Dash program
- annotation and analysis program
- annotation CSV
- feature summaries
- representative activity graphs and webcam images
- sample matching CSV/JPG capture pairs

Note: Arduino IoT Cloud Thing-to-Thing synchronisation failed during final data collection with a "Failed to sync properties" error. The final dataset was collected using a direct smartphone sensor stream while retaining the Python dashboard, 10-second segmentation, webcam capture and analysis workflow.
